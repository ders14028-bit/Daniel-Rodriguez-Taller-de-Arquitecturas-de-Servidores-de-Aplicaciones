Reflexion Lab - MicroSpringBoot

Servidor HTTP con anotaciones @RestController, @GetMapping y @RequestParam.

Endpoints Dinamicos

  • / -> Mensaje base del controlador Hello
  • /greeting -> Saludo por defecto
  • /greeting?name=Daniel -> Saludo personalizado
  • /greeting?name=Arquitectura -> Otro ejemplo

Recursos Estaticos

  • /index.html
  • /logo.png

Notas de Prueba

Si alguna URL devuelve Not Found, verifica que el servidor este corriendo en http://localhost:8080.

Comando de ejecucion recomendado:

java -cp target/classes co.edu.escuelaing.reflexionlab.Main
